## Optional: Save Data with Turso Database

⚠️ **Note:**
If you want to store the scraped data using my Turso database with a UI dashboard, you also need to clone the **scrapper-leads** repository.

### Steps

1. Clone the scrapper-leads repo:

```bash
git clone <scrapper-leads-repo-url>
```

2. Install dependencies:

```bash
npm install
```

3. Run the project:

```bash
npm run dev
```

This project provides:

- Database integration (Turso)
- UI dashboard for viewing scraped leads

Make sure both the extension and the scrapper-leads project are running and properly connected for full functionality.
